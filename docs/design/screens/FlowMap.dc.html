Rules every screen follows
• Every figure says what it's based on (connected accounts, last sync).
• Stale, failed or missing accounts are named — never estimated.
• Debts are shown separately and never counted as cash.
• The agent never guesses a price or a figure; it asks or says so.
• Status is text + icon, never colour alone. Touch targets ≥ 44px.
• Consent is checked on the server for every read and every agent tool.
